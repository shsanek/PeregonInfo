# W8 economy: prototype session simulation

Generated by `peregon_economy_sim --seed 7` (60 min session, 200 synthetic players). Content hash 0x2207e6ed, balance hash 0x06536fb7, rules hash 0xdf193e24, report hash 0x4ca3f1d2.

Policies: `route` values travel time, `tank` durability, `speed` engine power, `handling` grip and stability, `balanced` all four equally, `saver` never buys (pure affordability). A utility player buys the next-tier part with the best value per cost (coupons + parts at trader price) and saves for it when it is not affordable yet.
